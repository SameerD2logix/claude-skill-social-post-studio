# Platform reference (checked November 2026; platforms change limits, re-check yearly)

## LinkedIn
- Post limit 3,000 characters. Only ~210 characters show before "…see more": the first line is the hook.
- Best: 600–1,300 characters, short paragraphs, a question at the end. 3–5 hashtags.
- Links in the post are fine (some creators put them in the first comment).

## Instagram
- Caption limit 2,200 characters; ~125 show before "more". Max 30 hashtags; 5–15 relevant ones work best.
- Links in captions are **not clickable**: use "link in bio" or "DM us".

## TikTok
- Caption limit 2,200 characters, but people read only the first line. Keep it < 300.
- The video's first 2 seconds decide retention; the caption supports it. 3–5 hashtags.

## YouTube Shorts
- Title limit 100 characters; under 60 shows fully on phones. Description limit 5,000.
- Add `#Shorts` for discovery. Links in the description are fine.

## X (Twitter)
- 280 characters for standard accounts. Every URL counts as 23 characters.
- 1–2 hashtags at most.
